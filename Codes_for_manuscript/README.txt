Source of data:
1.The simulated Pacbio-like sequencing data in the `./Data_simulated/` folder are generated by VarSim and PBSIM2 with parameter setting: Read length (mean 5,000 bp and sd 1,000 bp), accuracy (95%) and sequencing depth (20x).
2.Access GIAB Consorium HG002 Dataset and Human Genome Assembly GRCh37 reference:
```
mkkdir -p ref giab
FTPDIR=ftp://ftp-trace.ncbi.nlm.nih.gov/giab/ftp/data/AshkenazimTrio/analysis/
curl -s ${FTPDIR}/NIST_SVs_Integration_v0.6/HG002_SVs_Tier1_v0.6.bed > giab/HG002_SVs_Tier1_v0.6.bed
curl -s ${FTPDIR}/NIST_SVs_Integration_v0.6/HG002_SVs_Tier1_v0.6.vcf.gz > giab/HG002_SVs_Tier1_v0.6.vcf.gz
curl -s ftp://ftp-trace.ncbi.nih.gov/1000genomes/ftp/technical/reference/phase2_reference_assembly_sequence/hs37d5.fa.gz > ref/human_hs37d5.fasta.gz
gunzip ref/human_hs37d5.fasta.gz
sed -i '/^[^>]/ y/BDEFHIJKLMNOPQRSUVWXYZbdefhijklmnopqrsuvwxyz/NNNNNNNNNNNNNNNNNNNNNNNNNNNNNNNNNNNNNNNNNNNN/' ref/human_hs37d5.fasta
curl -s https://raw.githubusercontent.com/PacificBiosciences/pbsv/master/annotations/human_hs37d5.trf.bed > ref/human_hs37d5.trf.bed
```
3.Use of Truvari for comparison
(a)Download the GIAB Consorium HG002 Dataset and Human Genome Assembly GRCh37 from Step 2 ;
(b)Convert combine results into VCF files (Take `result_HG002/res_D_0.95.csv` as an example);
```
python vcf.py result_HG002/res_D_0.95.csv result_HG002/res_D_0.95.vcf
bgzip -k result_HG002/res_D_0.95.vcf
tabix result_HG002/res_D_0.95.vcf.gz
```
(c)Truvari
```
truvari bench -b ./giab/HG002_SVs_Tier1_v0.6.vcf.gz -c result_HG002/res_D_0.95.vcf.gz -o result_HG002/res_D_0.95 --dup-to-ins --passonly --includebed ./giab/HG002_SVs_Tier1_v0.6.bed -p 0 -r 1000 -P 0.5
```
